它不评模型聪不聪明。它检查规则有没有真的执行、自动化能不能重跑，以及哪些结果仍需人在真实宿主里确认。It does not grade a model. It checks whether rules run, automation can be repeated, and what still needs a human in the real host.

检查方法The method

一次检查，先把问题问对。One audit starts with the right questions.

A

写在文档里的规则，真的会拦住错误吗？Can a written rule actually stop an error?

Harness Check 会沿着 Hook、任务合同和安全门去找执行证据。只有提示词，没有可执行入口，不算通过。Harness Check follows hooks, task contracts, and safety gates for execution evidence. A prompt alone is not a pass.

B

这次绿了，下次还绿吗？Will it pass the same way next time?

检查器要求正反例、退出码和可定位的失败标签，让 CI 的结果不是一句“已完成”。Fixtures, exit codes, and named failures keep CI results from collapsing into a vague “done”.

C

哪些地方不能由自动化替人担保？What should automation never promise for a person?

真实宿主烟测、发布判断和人工观感会被单独列出。没有做过，就不会被伪装成通过。Real-host smoke tests, release calls, and human judgement stay separate. Untested work is never dressed up as passed.

真实输出A real run

结果要能看见来路。A result should show where it came from.

同一套检查分为工作区、暂存区和 CI 三种模式。报告会把自动化结果、已有证据与仍待人工确认的事项分开，而不是合成一个看似权威的总分。The same suite runs for the working tree, staged changes, and CI. Its report separates automated results, recorded evidence, and human follow-ups instead of inventing one authoritative score.

先检查你眼前这份工作区。Check the workspace in front of you.

在已经接入 Harness 的项目根目录运行。它不会替你的项目生成规则，而是检查你已经声明的规则是否形成闭环。Run this at the root of a project that already has a Harness. It will not invent your rules. It checks whether the rules you declared form a loop.

检查边界Honest limits

自动化负责验证，
但不冒充判断。Automation verifies. It does not impersonate judgement.

它可以确认It can confirm

  • 配置、链接和脚本是否真实存在Whether config, links, and scripts exist
  • 正反例与退出码是否按约定工作Whether fixtures and exit codes work as agreed
  • CI 是否能重跑同一批自动化检查Whether CI can repeat the same automated checks

它不会声称It will not claim

  • 真实宿主里的每种交互都已测试Every real-host interaction was tested
  • 内容质量、审美或发布结果已经被机器定论Content, taste, or publishing outcomes are settled by a machine
  • 未被证据支持的“全部完成”“Complete” without supporting evidence

为需要长期维护 Agent 工作流的人而做。Built for people maintaining Agent workflows over time.
